# Useful Userscripts

A collection of helpful [Tampermonkey](https://www.tampermonkey.net/) / [Violentmonkey](https://violentmonkey.github.io/) userscripts designed to enhance everyday web browsing and productivity.

## Included Scripts

* **[Sudoku Notes Shortcut.js](Sudoku%20Notes%20Shortcut.js)** – Adds convenient keyboard shortcuts for taking or toggling notes while playing online Sudoku puzzles.

## Installation

1. Install a userscript manager extension for your browser (such as Tampermonkey or Violentmonkey).
2. Click on the script you want to install from this repository.
3. Click **Raw** to let your extension automatically prompt you to install it.
